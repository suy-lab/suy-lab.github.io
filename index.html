    Settings

    Automatic saving to GitHub

    Your entries save themselves to a private repository a few seconds after each change, and load on any device you connect. The site stays public; only a browser with your token can see your entries.

    1. On GitHub, create a private repository named research-journal-data. It can stay empty.
    2. Create a fine-grained token with access to only that repository and Contents: Read and write.
    3. Paste it below and press Connect. You only do this once per browser.
    Advanced

    Privacy on this device

    Lock the journal with a passcode. Your entries and GitHub token are then stored encrypted (AES-256) in this browser, and the journal asks for the passcode when you open it, or after 15 minutes away.
